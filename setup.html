Activer toutes les fonctions

Le filtrage de texte fonctionne dans Chrome. Pour trouver de nouvelles vidéos, vérifier les abonnés et examiner les miniatures, lancez aussi le serveur Python sur le même ordinateur que Chrome.

1. Installer et lancer le serveur

Dans PowerShell, ouvrez le dossier téléchargé de FeedControl puis exécutez :

py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe ai_server.py

Gardez cette fenêtre ouverte. Pour mettre à jour un serveur déjà lancé : Ctrl+C puis relancez la dernière commande depuis le nouveau dossier. Revenez dans le popup et cliquez sur Actualiser le diagnostic.

2. Autoriser les nouvelles vidéos YouTube

Une clé YouTube Data API est nécessaire pour la recherche automatique. Elle reste dans le serveur, jamais dans l’extension.

  1. Dans Google Cloud Console, créez ou choisissez un projet puis activez YouTube Data API v3.
  2. Dans API et services → Identifiants, créez une clé API. Restreignez-la à YouTube Data API v3 et à votre usage serveur.
  3. Si le fichier .env n’existe pas, copiez .env.example sous le nom .env dans le même dossier que ai_server.py.
  4. Ouvrez ce fichier dans votre éditeur, renseignez YOUTUBE_API_KEY= avec la clé, puis sauvegardez et redémarrez Python.

Ne partagez pas votre clé dans un message, une capture ou GitHub. Si le quota est épuisé ou la clé refusée, le panneau l’indique. Les liens de recherche YouTube restent disponibles.

3. Reconnaître les miniatures

Les dépendances de l’étape 1 permettent d’examiner réellement les pixels. Pour lire le texte incrusté, installez Tesseract OCR et assurez-vous que tesseract est accessible dans le PATH, puis relancez Python.

Pour un modèle multimodal local plus général : installez Ollama, puis téléchargez un modèle de vision tel que qwen2.5vl:3b. Ajoutez FEEDCONTROL_VISION_MODEL=qwen2.5vl:3b dans .env, puis relancez Python. Ce téléchargement peut être volumineux et le fonctionnement dépend de votre ordinateur.

Sans modèle visuel, les pixels et l’OCR restent utilisables. Une miniature monochrome n’est pas une preuve de motivation ; des annotations rouges ne prouvent pas une tromperie. Aucun visage connu n’est identifié automatiquement et la vidéo elle-même n’est pas regardée.
