# FeedControl V4

Extension Chrome de contrôle du flux YouTube : thèmes, exclusions, découverte officielle et suivi local avec consentement.

Consultez [le guide d’installation et de vérification en français](README_V4.md) et [l’état réel des fonctions](CHANGELOG_V4.md).

Démarrage : `python ai_server.py`, puis charger ce dossier dans `chrome://extensions` (mode développeur).
